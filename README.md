# ISM2411 Lab 12 — Read a Sales CSV, Write a Cleaned Report

**Name:** Amelie Edwards

## How to Run

From the `ism2411-lab12` folder, run:

```bash
python3 csv_practice.py
```

## Description

This lab uses Python to read sales data from a CSV file, calculate total revenue, filter orders over $100, and create a cleaned CSV report. It also summarizes revenue by product and records each program run in a log file.

## Files

- `csv_practice.py` — Python script containing the lab exercises.
- `data/sales.csv` — Original sales data.
- `data/cleaned.csv` — Filtered sales report.
- `data/run_log.txt` — Log of program runs and total revenue.
